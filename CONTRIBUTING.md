# Mitwirken

Danke für dein Interesse! Fehler, Ideen und Verbesserungen gern als Issue oder Pull Request.
Offene Punkte stehen in [`IDEEN.md`](IDEEN.md).

## Grundregeln

- **Keine echten Daten:** niemals `payload.js`, Webhook-URLs oder PINs committen.
- Keine Abhängigkeiten, kein Build-Schritt, keine externen Ressourcen.
- Sicherheitsrelevante Änderungen bitte im Pull Request begründen.
- Jede sichtbare Änderung in [`CHANGELOG.md`](CHANGELOG.md) unter `## [Unveröffentlicht]` eintragen.

## Lizenz

Mit einem Beitrag stimmst du zu, dass er unter der [AGPL-3.0-or-later](LICENSE) veröffentlicht wird.
